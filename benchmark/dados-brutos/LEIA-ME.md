# Dados brutos do benchmarking de rede (PI3-31)

Uma pasta por rodada, gerada por `benchmark/coletar.sh`, no formato
`AAAA-MM-DD_HHMM_<origem>_rep<N>` (horário em UTC). O conteúdo de cada pasta
e o método estão em [`docs/benchmark-rede.md`](../../docs/benchmark-rede.md).

Não edite os arquivos de uma rodada: eles são a evidência. Uma rodada
contaminada (deploy no meio, VM fora do ar) é apagada inteira e refeita,
com o motivo registrado no Jira.

Dados sintéticos; telemetria de temperatura simulada.
